## 香港服务器租用价格为什么差这么远？

差别主要来自五个变量：线路、带宽与流量口径、硬件平台、资源是否独享、计费币种与周期。这五项任意一项变动，月费就能差出两三倍，跟“香港”这个地点本身关系不大。

**线路**是最贵的一项。普通国际 BGP 与大陆优化线路是两种成本结构。GoMami 香港节点走中国电信 CN2、中国联通 AS9929、中国移动 CMIN2 三网优化，官方文档标注香港到中国大陆延迟 **< 30ms**，官网首页则写全网 RTT **< 50ms**。传统香港独服报价单里那些 5M／10M 带宽的方案，走的是完全不同的出口。

**带宽与流量口径**决定了“能不能跑满”。GoMami 给的是 1–5Gbps 端口配每月固定流量（500GB–10TB），只计出站；传统独服常见“5M 不限流量”或“100Mbps 共享 2M 国际出口”。前者是短时间高吞吐，后者是长时间低速率，账单长得像，用途差很远。

**硬件平台**直接反映在价格上。GoMami 用的是 AMD EPYC 7763、Ryzen 9 9950X、EPYC 7663 这类服务器级 CPU 配 NVMe SSD；而 2022 年一份香港独服参考价表里，HK$1,300 档位对应的是 i3-2100 / 2GB / 500GB 这类旧平台。

**独享与共享**是最容易被忽略的一项。Pulse、Turin、Peak 都是 VPS，跟别人共用物理机；Forge 才是整机独享。把 VPS 月费拿去跟独服月费直接比，等于拿合租房租比整栋楼价。

**计费方式**也不一样。GoMami 按美元月付；传统香港 IDC 多按港币月付，预缴半年或一年有折扣。

**香港服务器租用一个月到底多少钱？**

**GoMami 的价格为什么比一般香港 VPS 贵？**
贵在三件事：三网优化线路（CN2 / AS9929 / CMIN2）、1–5Gbps 大端口、以及 EPYC 7763／Ryzen 9 9950X／EPYC 7663 这级硬件。香港节点相对同系列日本、新加坡还要再贵一截，Nano 差 US$20、Pro 差 US$100。

**只计出站流量是什么意思？**
用户上传到服务器的流量不计费，只有服务器往外送出的才算。对于以图片、视频、下载为主的站点，实际可用流量会比账面数字宽松。

**买完不满意能退吗？**
新购 24 小时内可申请全额退款，仅限首次购买，续费不退。退款批准后服务器与数据立即永久删除，记得先备份。

**到期没续费会怎样？**
到期当天服务立即暂停，没有宽限期；逾期 5 天终止，数据可能无法恢复。

**600Gbps 防护是不是就打不死了？**
不是。默认防护是 best-effort，高级清洗需要额外安排，触发条件与计费方式官方没有公开说明。IP 被黑洞的情况也不在退款范围内。
